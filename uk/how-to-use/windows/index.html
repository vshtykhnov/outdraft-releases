Як користуватися Outdraft на Windows

Встанови, підключи до Dota 2, грай. Кілька хвилин.

WindowsLinux

Встановлення

Завантаж Outdraft-windows-x86_64.exe і запусти. Він встановлюється лише для твого користувача, права адміністратора не потрібні.

Windows SmartScreen або Edge можуть попередити: застосунок поки без цифрового підпису. У SmartScreen натисни Докладніше → Усе одно запустити, в Edge — Зберегти.

Outdraft оновлюється сам.

Перший запуск

Outdraft додає файл Game State Integration, щоб Dota передавала йому дані гри. Перезапусти Dota 2 один раз після першого запуску.

Коли все працює, на стартовій картці видно ✓ Dota 2 підключено.

Налаштування Dota

Увімкни в Dota режим вікно без рамки або віконний.

Підходить будь-який формат екрана: 4:3, 5:4, 16:10, 16:9, 21:9, зокрема 4:3, розтягнутий на весь екран.

Як користуватися

  • Драфт: наведи на порожній слот, щоб побачити найкращих героїв для нього. Клацни, щоб закріпити список.
  • Матч: у вкладці Гра — збірка, скіли та фарм.
  • Додати Steam ID — бани проти твого пулу героїв.

Якщо Dota 2 не знайдено

В Outdraft натисни Обрати теку Dota 2 і обери теку dota 2 beta.

Де вона: у Steam відкрий Dota 2, потім ⚙ → Керувати → Переглянути локальні файли. Відкриється саме ця тека.
