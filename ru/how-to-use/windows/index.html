Как пользоваться Outdraft на Windows

Установи, подключи к Dota 2, играй. Пара минут.

WindowsLinux

Установка

Скачай Outdraft-windows-x86_64.exe и запусти. Он ставится только для твоего пользователя, права администратора не нужны.

Windows SmartScreen или Edge могут предупредить: приложение пока без цифровой подписи. В SmartScreen нажми Подробнее → Выполнить в любом случае, в Edge — Сохранить.

Outdraft обновляется сам.

Первый запуск

Outdraft добавляет файл Game State Integration, чтобы Dota передавала ему данные игры. Перезапусти Dota 2 один раз после первого запуска.

Когда всё работает, на стартовой карточке видно ✓ Dota 2 подключена.

Настройки Dota

Включи в Dota режим окно без рамки или оконный.

Подходит любой формат экрана: 4:3, 5:4, 16:10, 16:9, 21:9, в том числе 4:3, растянутый на весь экран.

Как пользоваться

  • Драфт: наведи на пустой слот, чтобы увидеть лучших героев для него. Кликни, чтобы закрепить список.
  • Матч: во вкладке Игра — сборка, скиллы и фарм.
  • Добавить Steam ID — баны против твоего пула героев.

Если Dota 2 не найдена

В Outdraft нажми Выбрать папку Dota 2 и выбери папку dota 2 beta.

Где она: в Steam открой Dota 2, затем ⚙ → Управление → Просмотреть локальные файлы. Откроется именно эта папка.
