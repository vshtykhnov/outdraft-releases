# Outdraft for Windows and Linux

Outdraft helps with Dota 2 picks, bans and builds, with recommendations during the draft and the match.

Website: [outdraft.org](https://outdraft.org)

## Download

- [Windows ZIP](https://github.com/vshtykhnov/outdraft-releases/releases/latest/download/Outdraft-windows-x86_64.zip)
- [Linux archive](https://github.com/vshtykhnov/outdraft-releases/releases/latest/download/Outdraft-linux-x86_64.tar.gz)
- [All releases and release notes](https://github.com/vshtykhnov/outdraft-releases/releases)

## Run

On Windows, extract the ZIP and run `Outdraft.exe` from the extracted folder. On Linux (Wayland), extract the `.tar.gz` and run `Outdraft`.

Keep all extracted files together. On Windows, use Dota 2 in borderless-window or windowed mode. Restart Dota 2 once after the first run so it loads the game integration. An internet connection is required for recommendations.

## Update

Close Outdraft, download the latest archive and extract it into a new folder. Run the application from that folder; replace the whole application folder when updating, not just the executable. Your settings are stored separately.
